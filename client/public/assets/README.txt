Portal logo
===========

The header and the browser tab use this file:

    logo.png

To use your own college logo, simply replace this file with your logo and keep
the file name as logo.png. No code change is needed.

Recommended image:
- PNG with a transparent background
- Square image, 320 x 320 pixels or larger
- The logo appears at 56 x 56 pixels in the site header

If you use a different file type, either convert it to PNG or update the two
references to /assets/logo.png in:
- client/index.html (browser tab icon)
- client/src/components/Header.jsx (header logo)
